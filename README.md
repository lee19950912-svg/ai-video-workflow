# AI 热点讲解片 · 一整套做法

这是我做「AI 热点讲解片」的全部做法：从拿到一条 AI 新闻，到出一条一两分钟的横屏讲解视频。
片子的样子：白底，一个人讲，左边一张大卡放这件事本身的真画面（官方演示、官方图、官方网页截图），右边站着一个叫 **Aha** 的小团子讲解，底下是字幕。

整个过程是我和 Claude Code（Anthropic 的命令行 AI 助手）一起做的：我给题目、看稿子、听声音、打分；它核实事实、写稿、调配音、排时间、写画面代码、自查。所以这里的文档有两种口气：给人看的（"你"指我），和给 Claude 看的规矩。

> 路径说明：文档里的 `E:\自媒体\…`、`E:\tools\…` 是我自己电脑上的位置，照着做的时候换成你自己的。

## 一期片子的九步（细节在流程文档里）

1. **核实**：原帖、官方文档、至少一家媒体，写成事实表。稿子里每句话对应一行出处。
2. **找真画面**：官方演示视频、官方图；没有视频就截官方网页。
3. **写稿**：像朋友聊天，有自己的看法；写完跑自查。
4. **配音**：我点头后才配。整篇一次合成，再自动切成一句一句（分开合成每句的调子会不一样）。
5. **排时间**：每句调到一样响，按意思给停顿，导出给画面用。
6. **做画面**：用代码写（Remotion），先出静帧给我看。
7. **出片**：渲染、调响度。
8. **交片前自查**：画面逐秒看，声音逐句量。
9. **打分以后**：高分段请两位没看过制作过程的 AI 审查员，分开审画面和声音。

## 这里没有、要你自己准备的

这些东西有的是密钥，有的版权不在我，所以没放进来：

| 东西 | 怎么办 |
|---|---|
| 配音的密钥 | 自己去火山引擎开通豆包语音合成，拿到 Key 后运行 `工具/doubao-voice/设置Key.bat` 填进去。按字收费，两分钟的稿子大约 5 毛 |
| 官方演示、官方图、网页截图 | 每期自己去官方帖子里找；用法见 `授权与合规.md` |
| 各家公司的 logo | 去各家官网的品牌页下载，原样用 |
| 字体 | 用的是小米的 MiSans，去它官网下载 |
| 配乐 | 我用的是 Mixkit 上的一首免费曲子（Pop Track 03），自己去下；正在换成用 Suno 现做 |
| 音效 | 自己找几声短的（转场声、轻响） |
| 去 AI 味的检查工具 | 别人的开源项目：https://github.com/larashero3-dotcom/lieflat-less-ai-tone （非商用许可） |
| 成片、配音、静帧 | 里面有各家公司的官方画面，没放 |

## 要装的软件

- [Claude Code](https://claude.com/claude-code)（或者别的能读写文件、跑命令的 AI 助手）
- Node.js（跑 Remotion 出画面）、Python 3、ffmpeg
- 对稿用到 faster-whisper（Python 包）

画面工程怎么搭：新建一个文件夹（路径里不能有中文），把 `工具/画面工程/` 里的两个文件放进去，`npm install`；再把 `_讲解片模板/样板代码/` 里的 `.tsx` 按 `_讲解片模板/README.md` 最后一节说的位置放进 `src/`，`tools/` 放到工程根目录。

## 几句实话

- **这不是一键出片的工具**，是一套做法加一堆小工具。每期都要人看稿子、听声音、打分。
- **AI 听不到声音。** 它只能量响度、音高、停顿这些数，好不好听要人来听。
- **Remotion** 公司使用需要买许可，个人和小团队免费，用之前看它官网的说明。
- 豆包配音的商用条款我还没核实，现在的片子都没开收益。
- 这个仓库没有附开源许可。
