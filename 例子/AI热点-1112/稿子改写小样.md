## 一、AI 味出在哪（我的诊断，不是用户的话）

1. **一个比方从头套到尾。** 招聘会 → 岗位 → 新同事 → 组长 → 骨干 → 实习生 → 美工，五件事每件都对上号。真人打比方是随口一句，说完就扔。这条还是我自己写进流程的规矩（"找一个看法把几件事串起来，再配一个生活里的比方"），规矩本身在制造这个味道。
2. **五段一个模子。** 每段都是"谁家的 → 能干什么 → 一句限制 → 一句点评"，开头是"先说 / 第二个是 / 第三个是 / 第四个是 / 再来是"。这就是清单，只是换了个说法。
3. **工整的对仗句。** "高薪的骨干，便宜的实习生""一张草图，一套主图就齐了""它不写字，只做判断"。写稿规范里明写着不要对仗金句，我没守住，自查工具也不查这个（它给这篇稿子的结论是"没发现问题"）。
4. **结尾是套路。** "所以该练的是…… / 还有…… / 换你说……"，等于总结加三条建议加一句问观众。规范写的是"结尾不做总结"。
5. **平均用力，没有态度。** 五件事一样长、一样客气，没有一句"这条跟你没关系""这个我不信"。真人会偏心：有的一句带过，有的讲透。
6. **每句都是完整的书面句。** 27 句里没有一句半截话、没有一次改口、没有一个"对了""说实话"。句子长短也差不多。
7. **全是转述，没有"试过"。** 稿子是五条公告的摘要。真人作者的稿子里最有人味的是"我用了、我踩了坑、我不推荐"。这一条靠改措辞改不出来。

## 二、两段改写

## 三、改了什么
- 去掉从头套到尾的比方，想打比方就随口一句。
- 不平均讲，敢说"这条你用不上"。
- 先说观众在乎的（钱、能不能用），公司名往后放。
- 句子有长有短，留"说实话""对了""我看啊"这种口气。
- 不写对仗句，结尾不总结。
